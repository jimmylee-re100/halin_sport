SECTION 1 · USER FLOW

主流程：使用者從上到下走 9 個區塊

每一個區塊跑完才進下一個，使用者保有「重新生成」與「修改」的決策權。文案／圖／影各自先做主版，發佈時再自動改寫到三平台。

階段 A · 輸入
1

輸入主題與素材

使用者輸入這次要做的內容主題（例：父親節）、主推商品、檔期、活動類型。可上傳參考圖、商品照、品牌素材。
表單輸入 檔案上傳 必填欄位
→ 產出
結構化輸入資料（JSON）

階段 B · AI 生成（主版）
2

文案生成（主版）

Claude API 依輸入產出多版主版文案候選。使用者選一版，可手動編修或重新生成。確認後鎖定主版。
Claude API 多版候選 手動編修
→ 產出
主版文案 1 則
▼
3

圖片生成（主版）

依文案主題與品牌素材，呼叫 Midjourney（海報風）或 FLUX（商品圖）產出多張候選。使用者選 1 張或多張。
Midjourney FLUX.1 多張候選
→ 產出
主版圖 1–N 張
▼
4

視頻生成（主版）

用主版圖作為 reference，呼叫 Runway 產出 15 秒短片。或選擇「靜圖動態化」備案路徑（CapCut／AE）。
Runway Gen-3 15 秒 備案：靜圖動態化
→ 產出
主版視頻 1 段
▼
5

主版預覽 + 確認

把文案、圖、影合併呈現，使用者檢視整體效果。可回到任一步驟重新生成；確認後進入跨平台改寫。
合併預覽 回退 主版鎖定
→ 產出
已確認主版包
▼

6

跨平台自動改寫

主版確認後，系統自動產出 FB／IG／Threads 三平台版本：文案語氣調整、圖片裁切（1:1／4:5／9:16）、視頻規格適配。
自動改寫 FB 長文 IG 視覺 Threads 短句
→ 產出
三平台版本各 1 套
▼
7

三平台預覽 + 確認

並排呈現 FB／IG／Threads 三版本，使用者逐一檢視。可微調文案、換圖、單獨重做某一平台、回退至第 6 區重新改寫。確認後鎖定，不可再改。
三欄並排 逐一微調 單平台重做 三版鎖定
→ 產出
三平台已確認版本

總公司 3 個 分店 141 個 常用組合

發佈帳號清單

排程設定

選擇發佈時機：即時發佈，或指定日期時間定時發佈。可針對不同平台設定不同發佈時間（FB 早、IG 晚）。
即時 定時 分平台時段
→ 產出
排程設定

SECTION 5 · ROADMAP

POC 開發節奏（4 階段）

採抽時間推進，不綁定固定週數。每階段完成後再進下一階段。

STAGE 1

骨架搭建

  • 建 React 10 區塊骨架
  • 建 FastAPI 路由
  • 建 PostgreSQL 結構
  • UI 線框可走完流程
STAGE 2

AI 服務串接

  • 串 Claude API 文案
  • 串 Midjourney／FLUX 圖
  • 串 Runway 視頻
  • 串通主版生成
STAGE 3

跨平台 + 帳號

  • 跨平台改寫邏輯
  • 三平台預覽 UI
  • 帳號選擇 UI
  • 排程設定 UI
  • 模擬發佈紀錄
STAGE 4

整合 + 父親節 demo

  • 整合測試
  • 跑父親節 POC
  • 產出 demo 包
  • 給總經理檢視
